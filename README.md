# TabNews Clone

Projeto de estudo em Next.js criado no curso.dev para construir um clone do TabNews.

## Rodar localmente

Com Git e nvm instalados, use a versão de Node do arquivo `.nvmrc`.

```bash
git clone https://github.com/bagaaz/tabnews-clone.git
cd tabnews-clone
nvm install
nvm use
npm ci
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).
